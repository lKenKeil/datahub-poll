# ASKIO 공식 발행 계정

공개 투표의 상세 화면은 공식 발행 기록에 고정 표시 이름 `ASKIO 공식`, 저장소의 B1 기반 심벌, `공식 운영 계정` 배지를 표시합니다. 배지를 열면 소개를 볼 수 있습니다. 익명으로 발행하면 작성자 줄이 숨겨집니다. 공개 응답에는 작성자 UUID나 관리 자격 증명이 포함되지 않습니다.

## 관리 권한

- `official_poll_publishers`는 공식 발행에 등록한 Auth UUID와 활성 상태를 기록합니다. 사용자·서비스 역할에는 등록을 변경할 권한이 없습니다. 기존 관리자 권한 체계는 별도로 동작합니다.
- 신규 공식 투표는 작성자와 소유권 행을 같은 트랜잭션으로 저장합니다. 공식 투표의 소유권 행에 토큰 해시 대신 `NULL`을 저장하고, 브라우저 토큰을 발급하지 않습니다. 기존 일반 투표는 토큰 해시와 기존 소유권 흐름을 계속 사용합니다. 소유권 행 자체가 없으면 계정 관리 권한도 없습니다.
- 공식 투표는 활성 상태인 등록 계정이 저장된 작성자 UUID와 일치하고, 서버에서 세션을 검증한 경우에만 수정·삭제할 수 있습니다. 새 브라우저에서도 로그인 후 동일한 관리 기능을 사용합니다. 기존 구조 편집 잠금 및 삭제 로직이 적용됩니다.
- `ASKIO_OFFICIAL_ACCOUNT_USER_ID` 환경변수는 폐기했습니다. 실제 분류와 발행 권한은 대상 DB에서 검증합니다. 공식 소유권 행에 토큰 해시를 복원하는 업데이트는 거부됩니다.

## 등록·교체·롤백

1. 별도 이메일로 대상 환경의 ASKIO에서 이메일 OTP 가입·로그인을 완료합니다. 운영 담당자 두 명이 대상 프로젝트와 Auth UUID, 활성화할 계정이 일치하는지 확인한 뒤 DB 관리자 권한으로 발행자를 등록합니다. 운영 등록과 변경에는 별도 승인이 필요합니다.
2. 기존 코드로 발행된 공식 투표가 있다면, 먼저 공개 링크에서 정확한 투표 ID를 확인합니다. 승인한 목록만 현재 작성자와 소유권 행을 대조한 뒤 같은 작업 시간에 해시를 `NULL`로 전환합니다. 기존 토큰은 폐기됩니다. 이번 migration은 어떤 계정도 등록하지 않으며 기존 토큰을 일괄 변환하지 않습니다. 1·2편 등 일반 콘텐츠는 별도 이전 승인 대상입니다.
3. 등록·비활성화·교체·기존 투표 전환 전에는 투표 생성과 소유자 PATCH/DELETE 요청을 대상 배포 전체에서 일시 중지하고 진행 중인 요청을 끝냅니다. 투표·댓글 읽기와 일반 투표 참여는 기존 흐름을 사용합니다. 기존 계정을 비활성화하고 새로 확인한 계정을 활성화합니다. 이전 계정의 투표에는 공식 표시와 토큰 폐기가 유지되며, 관리가 잠깁니다. 새 계정으로 권한이 자동 이전되지는 않습니다. 과거 투표의 이전은 별도 승인·감사·복구 계획이 필요합니다.
4. 롤백 시에도 migration과 공식 소유권 행을 유지합니다. 이전 앱은 `NULL` 해시를 유효한 토큰으로 인정하지 않으므로 공식 투표 관리가 잠깁니다. 이전 앱 UI는 공식 투표에 쓸 수 없는 토큰을 표시할 수 있으므로 공식 발행을 중지합니다. 환경변수 기반 배지를 쓰던 버전으로 돌아갈 경우 폐기된 변수를 제거한 상태에서 복구합니다. 이전 토큰을 되살리거나 계정 Auth UUID를 바꾸는 복구 대신, DB를 유지한 채 수정된 앱으로 전진 복구합니다.

## Production 적용 전 체크리스트

- [ ] 스테이징에서 대상 스키마·migration 이력·기존 grants를 비교했다. 현재 서비스 전용 생성 RPC가 토큰 해시를 저장한 뒤 작성자 UUID를 설정하고, `poll_ownership`에 해당 행이 생성되는지 확인했다.
- [ ] 로컬 일회용 DB에서 [공식 발행 SQL 회귀 테스트](../supabase/tests/official_poll_management.sql)를 통과했다. 스테이징에서는 [공식 발행 migration](../supabase/migrations/20261119000000_add_official_poll_management.sql)을 앱 배포 전에 적용했다. 일반 계정·비로그인 역할의 공식 발행자 레지스트리 조회·변경, RPC 직접 실행, 소유권 해시·작성자 UUID 조회가 거부되는지 확인했다. 기존 공개 투표·댓글·투표자 API는 정상이다.
- [ ] 공식 계정이 깨끗한 브라우저에서 로그인해 자신이 공개한 테스트 투표를 토큰 없이 관리한다. 비로그인·일반 계정·다른 공식 계정·비활성 계정·만료 세션·교차 출처 요청은 거부된다. 일반 투표는 기존 토큰으로 관리되며, 공식 투표의 예전 토큰은 거부된다.
- [ ] 스테이징에서 계정 비활성화·교체와 앱 롤백을 시연했다. 이전 버전에서도 공식 투표 토큰이 유효하지 않고, 새 계정이 과거 투표를 수정할 수 없다. 브라우저별 게스트/로그인 투표, 변경·취소, 집계·댓글을 확인했다.
- [ ] 승인된 B1 마스터 원본과 실제 배지 자산을 대조했다. 저장소 심벌은 B1 레퍼런스에서 따온 경로로 확인되지만, 승인 마스터 원본과의 동일성은 별도 확인이 필요하다.
- [ ] 운영 SQL·계정 등록·코드 배포·콘텐츠 발행을 각각 승인받았다. 기존에 발행된 공식 투표가 있다면 대상 ID와 토큰 전환 계획을 별도 승인했다. 운영 인스턴스 전환과 쓰기 중지·재개 담당자를 정했다.

발행 승인 후에만 공식 계정으로 `/create`에 들어가 3편 질문과 보기를 등록합니다. 배지를 표시하려면 `익명으로 올리기`를 해제합니다. 로그아웃 창과 모바일에서 작성자 표시와 공개 URL을 확인한 뒤 블로그에 연결합니다.
